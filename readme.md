Mimi — WhatsApp Scam and Fraud Detection Agent

Mimi is an AI-powered WhatsApp bot that analyzes incoming messages, voice notes, and links in real time to detect scams, phishing attempts, and financial fraud. It uses Groq for language reasoning, VirusTotal for URL and file scanning, and AWS Transcribe for voice message analysis. When a high-confidence threat is detected, Mimi can alert a trusted contact automatically.
